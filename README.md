# Shmael13.github.io

Source for my portfolio site at <https://shmael13.github.io>.

It's a single static page (`index.html`, `style.css`, `lab.js`) with no build step. The hero is a small interactive demo of look-ahead bias: drag the decision day and switch between a trailing and a centered moving average to see when a signal starts reading data from the future. That's the problem my [leakproof](https://github.com/Shmael13/leakproof) project catches at check time.

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
